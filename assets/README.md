# Assets

`hand-right.glb` is the right-hand model from the `generic-hand` profile of
[@webxr-input-profiles/assets](https://github.com/immersive-web/webxr-input-profiles)
(version 1.0.20), distributed under the MIT license in `LICENSE-hand-model.md`.
It is used unmodified; the left hand is drawn by mirroring it.
