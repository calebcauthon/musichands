# Assets

## Hand model

`hand-right.glb` is the right-hand model from the `generic-hand` profile of
[@webxr-input-profiles/assets](https://github.com/immersive-web/webxr-input-profiles)
(version 1.0.20), distributed under the MIT license in `LICENSE-hand-model.md`.
It is used unmodified; the left hand is drawn by mirroring it.

## Piano

`piano/` holds recordings from the
[Salamander Grand Piano V3](https://archive.org/details/SalamanderGrandPianoV3)
by Alexander Holm, a Yamaha C5 sampled every minor third, licensed under
[Creative Commons Attribution 3.0](http://creativecommons.org/licenses/by/3.0/).
These are the MP3 conversions published with [Tone.js](https://github.com/Tonejs/audio),
unmodified.
